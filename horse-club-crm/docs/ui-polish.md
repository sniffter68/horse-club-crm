# UI Polish · 17.11.2026

Обновлены шрифты Manrope/Inter с системными fallback, табличные цифры, общие тёплые тени, оформление приветствия и входа, линейные иконки 1.75px, цветные полосы занятий и микроанимации. Локальные SVG исключены из accessibility tree. Новые эффекты поддерживают reduced motion. Индикатор времени использует Europe/Moscow, обновляется каждые 30 секунд и отображается только в выбранном сегодняшнем дне.

Runtime-токены и их адаптеры описаны в `DESIGN.md`. Бизнес-операции, существующие data-testid и ARIA-атрибуты сохранены. Зависимости и схема БД не менялись; миграция Prisma не требуется.
