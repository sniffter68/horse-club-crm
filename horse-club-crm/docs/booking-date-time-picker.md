# Подтверждение даты и времени записи — 22.10.2026

Общий `frontend/src/components/BookingDateTimePicker.tsx` используется в
`schedule/TriadBookingModal.tsx`, `schedule/index.tsx` и `dashboard/QuickActions.tsx`.

- Стандартный footer Ant Design явно включает «ОК» (`needConfirm`) и «Сейчас».
- «ОК» применяет дату, часы и минуты в форму и закрывает календарь.
- «Сейчас» сразу применяет текущее московское время и закрывает календарь.
- Escape закрывает календарь, оставляя форму открытой.
- Попап смещается в видимую область окна; при ограниченной высоте прокручивается,
  footer закреплён. Цвета наследуются из текущей темы, включая тёмные шторки.
- Для строковых значений `BookingDateTimeInput` сохраняет ссылку на Dayjs между
  рендерами: асинхронная проверка ресурсов не сбрасывает неподтверждённую дату.
- Формат API и схема БД не менялись; миграции Prisma не требуются.
