# Компактные карточки расписания — 20.10.2026

В календаре FullCalendar и расписании по ресурсам используется общий `ScheduleEventContent`.
В цветной плашке две строки: московское время начала/окончания и тренер.
Пустое имя заменяется на «Без тренера», для экскурсии — «Экскурсия (N чел.)».
Клиент, услуга, лошадь, нагрузка, статусы, расчёты и действия сохранены в существующих карточках по клику.

Содержимое ограничено границами события, длинные строки обрезаются многоточием.
Получасовой слот FullCalendar имеет высоту 48px для двух строк; одновременные события размещаются без перекрытия.
Для ресурсов сохранён масштаб времени; минимальная высота события больше не расширяет его за заданный интервал.
Подсказка содержит время, тренера, участников, лошадей, известный статус оплаты и статус занятия.
Суммы берутся из общего расчёта, используемого бейджем оплаты; данные оплаты бронирований не выдумываются.
Подсказка и доступное имя обновляются при изменении события.
