# Проверка живого поиска — 06.11.2026

Реализованы общий `LiveSearch`, подсветка совпадений, поиск без Enter во всех отдельных строках поиска списков CRM, поиск клиентов и лошадей в текущей шторке записи. Основные каталоги открывают карточку по выбору подсказки. Сервер учитывает породу и владельца лошади, а также телефон без маски и префиксы 7/8.

Проверки:

- Backend: `npm run typecheck`, `npm run lint`, `npm run build`, `npm test` — успешно. 659 тестов прошли, 20 пропущены штатными условиями окружения. Линтер сообщает три прежних предупреждения в `vet-records.test.cjs`, `dashboard.test.cjs`, `audit-http-20261019.cjs`; ошибок нет.
- Frontend: `npm run typecheck`, `npm run lint`, `npm run build`, `npm test` — успешно. 19 файлов, 162 теста.
- `npx playwright test --project=mock live-search.spec.ts` — 8 сценариев прошли в Microsoft Edge. Клиенты/лошади/тренеры на 1280 и 390 px: debounce, отсутствие лишнего запроса при очистке, сохранение фокуса, клавиатурный крестик, медленный устаревший ответ, пустой результат, ошибка и восстановление, IME, подсветка, переход в карточку мышью и клавиатурой. Еще два сценария проверяют выбор клиента/лошади в актуальной шторке записи и disabled-состояние лошади на лечении.
- `python scripts/audit-ui.py . --mode strict` — 0 замечаний. Исходный аудит навыка без штатного JSX-адаптера ошибочно распознает Ant Design Select/Form.Item как HTML select/form; адаптер проекта сохраняет все правила и корректно обрабатывает JSX.
- `git diff --check` — успешно.

Ограничения: дополнительный запуск прежних сценариев `client-preferences.spec.ts` остановлен после ошибок ожидания старых диалогов «Бронирование тройного ресурса» / «Быстрое бронирование». В HEAD эти формы уже заменены общей шторкой «Записать на тренировку». Новые сценарии тестируют актуальную шторку. Весь набор legacy E2E не считается пройденным.

Телефонный SQL проверен mock-тестами, PostgreSQL локально не использовался. Схема БД не менялась; миграция и генерация Prisma Client не требуются.

В коммит входят только изменения задачи; существовавшие до начала работы `trainer-concurrency.diff` и `trainer-vk-binding.diff` сохранены отдельно.
