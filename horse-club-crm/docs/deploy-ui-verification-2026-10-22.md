# Проверка автодеплоя и изменений интерфейса

Дата: 22.10.2026, Europe/Moscow.

## Изменения

- Workflow `../.github/workflows/deploy.yml` расположен в фактическом корне Git и запускает существующий `deploy.sh` при push в `main`, через `appleboy/ssh-action@v1.0.3` и секреты `HOST`, `USERNAME`, `SSH_KEY`. Параллельные деплои исключены.
- `scripts/deploy-commit.ps1` определяет корень Git, проверяет ветку `main`, выполняет add/commit/push с остановкой при ошибке и восстановлением исходной папки. Скрипт сохранён в UTF-8 с BOM для Windows PowerShell.
- В расписании одна основная кнопка «Записать на тренировку». Прежняя форма занятия доступна через выбор слота календаря; соответствующие E2E обновлены.
- Ant Design Tooltip карты денников показывает конкретные сообщения сервера, включая имена лошадей и положение жеребцов, а также карантинную зону. Доступен по наведению и фокусу карточки.

## Успешные проверки

- Backend: `npm.cmd run typecheck`, `npm.cmd run lint` (Oxlint), `npm.cmd test`, `npm.cmd run build`. Тесты: 485 passed, 17 skipped, 0 failed. Oxlint: ошибок нет, три предупреждения в неизменённых тестах.
- Frontend: `npm.cmd run typecheck`, `npm.cmd run lint` (Oxlint), `npm.cmd test`, `npm.cmd run build`. Unit-тесты: 142 passed, 0 failed; Oxlint без предупреждений.
- Синтаксис workflow проверен через `js-yaml`, проверены push/main и версия action.
- PowerShell Parser: синтаксис корректен. Smoke-проверка с подменёнными Git-командами: успех, ошибки add/commit/push, неверная ветка и восстановление папки. Реальные commit/push не выполнялись.
- `python scripts/audit-ui.py . --mode strict --output test-results/deploy-ui-jsx-audit.json`: 0 ошибок. Прямой upstream-аудитор выдаёт 200 ложных срабатываний на JSX; проектный адаптер нормализует JSX без исключения правил.
- Playwright mock: все 8 сценариев карты денников прошли, включая tooltip, клавиатуру, узкий экран, права, ошибки и печать. Проверка одной кнопки записи прошла при ширине 1280 и 375 px. Сценарии бронирования, прав, ошибок ресурсов и доступности также прошли в расширенном прогоне.

## Ограничения расширенного E2E-прогона

Первичный прогон 87 сценариев: 79 passed, 8 failed. После исправления тестового помощника выбора слота три сценария нагрузки на 1280/320/768 px проходят. Сценарий отмены инициатором «Клуб» также прошёл при повторной проверке. Четыре остальных сбоя воспроизведены как на исходных файлах из HEAD, так и на итоговом коде (в обоих сравнительных прогонах: 5 passed, 4 failed):

1. Пересчёт нагрузки при изменении даты бронирования.
2. Время в payload переноса занятия: ожидается 09:00Z, фактически 07:00Z.
3. Отображение ошибки API нагрузки в форме.
4. Блокировка сохранения при медленной проверке и смене даты.

Сравнительные логи: `test-results/deploy-baseline-e2e.log`, `test-results/workload-final.log`. Итоговая проверка карты: `test-results/stall-final.log`; проверка открытия формы через календарь: `test-results/calendar-helper-final.log`. Исходные файлы после сравнительного запуска восстановлены с текущими изменениями.

Схема БД не менялась; новая миграция и генерация Prisma Client не требуются. Боевой деплой не запускался. Для активации нужны repository secrets и push workflow в `main`; инструкция: `docs/automatic-deploy.md`.
