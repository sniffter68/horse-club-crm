# Текущий баланс кассы и счета

По задаче владельца от 26.10.2026 остатки на дашборде и в разделе `/cash-desk` означают текущие средства всего клуба. Фильтры периода, кассира и смены влияют только на оборот и журнал операций.

Оба API используют `currentCashBalance` из `backend/src/payments/finance.service.ts` внутри транзакции RepeatableRead. Учитываются оплаченные неархивные поступления и неархивные, неотменённые расходы до текущего момента. Наличные и безналичные считаются отдельно через Prisma Decimal. Архив после очистки кассы исключается также из дневных показателей дашборда. Размен при открытии смены не создаёт новое поступление.

Карточка «Баланс кассы» — ссылка на существующий маршрут, доступная при праве чтения CASHBOX. Она поддерживает Enter, hover, focus-visible, нажатие и reduced motion. Новых визуальных токенов нет.

Без открытой смены текущий баланс продолжает загружаться; оборот отсутствующей смены и её журнал пусты. При незаданном произвольном периоде баланс также доступен. Ошибка запроса отображается явно, остаток не подменяется нулём.

Сводки используют Axios без отдельного React Query/SWR-кэша. Существующее событие `cash-desk-paid` обновляет дашборд и кассу после приёма оплаты, оплаты занятия, продажи абонемента, внесения/отмены расхода, инкассации и очистки журнала. При переходе между страницами выполняется новый запрос.

Проверки: `npm.cmd run typecheck`, `npm.cmd run lint`, `npm.cmd run build`, `npm.cmd test` в обоих проектах; браузерные сценарии `dashboard.spec.ts` и `cash-desk.spec.ts`. Регрессионный backend-тест `cash-balance.test.cjs` проверяет совпадение сумм, независимость от периода/кассира/смены и фильтры архива, статуса и текущего времени. Браузерные тесты проверяют переход мышью/Enter, экраны 1440/390 px, отсутствие смены, смену фильтров и восстановление после ошибки.

Полный строгий premium-аудит: 201 замечание как до, так и после изменений; новых замечаний нет. Сравнение выполнено с исходными файлами HEAD во временной копии проекта. Это отдельные прежние замечания статического аудитора, не ошибки Oxlint. JSON текущего аудита: `docs/cash-balance-premium-audit.json` (локальный игнорируемый артефакт).

Схема БД не меняется, миграция Prisma не нужна.

Результат проверок: typecheck и сборки обоих проектов успешны; Oxlint — без ошибок (3 прежних предупреждения backend); backend — 496 успешно, 17 пропущено; frontend — 142 успешно; Playwright — 42 успешно. После уточнения ожидания завершения загрузки два новых браузерных сценария повторно прошли.
