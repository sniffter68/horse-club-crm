# Быстрое создание клиентов

`Client.clientType`: `REGULAR` (по умолчанию, в том числе для существующих записей) или `ONE_TIME`. Телефон остаётся nullable и уникальным; отсутствие телефона не заменяется пустой строкой. `riderLevel` хранит необязательный уровень всадника.

API под существующей авторизацией каталога клиентов:

- `POST /api/clients/quick`: `{ name, phone?, isOneTime?, note?, riderLevel? }`. Имя очищается от лишних пробелов; `isOneTime` по умолчанию false. Заметка сохраняется в `preferences`. Возвращается созданная запись. ADMIN/MANAGER создают клиентов; TRAINER имеет только чтение каталога.
- `PATCH /api/clients/:id/convert-to-regular`: меняет только тип, повторный вызов безопасен. История тренировок, платежи и связи сохраняются.
- `GET /api/clients?clientType=ONE_TIME&q=Анна&_start=0&_end=50`: серверные поиск, фильтр и пагинация. Пустой `clientType` означает все типы.

`frontend/src/components/ClientSelectWithCreate.tsx` владеет поиском и созданием во всех формах привязки клиента: запись с дашборда, участники календаря, бронирование тройного ресурса, касса, заселение, договор постоя и продажа абонемента. Поиск ограничен 50 результатами; debounce 300 мс, устаревшие запросы отменяются. Текст поиска не попадает в URL. Выбранный клиент сохраняет подпись после обновления выдачи.

Создание открывается в компактном Ant Modal поверх исходной формы. Отмена и ошибки сохраняют исходные поля; успех выбирает возвращённый ID и возвращает фокус на селект. Касса сохраняет общую услугу, сумму, способ оплаты и комментарий; чужой абонемент/занятие сбрасывается при смене клиента. Создание клиента само по себе не проводит финансовых операций и не меняет правила допуска лошади к тренировке.

В списке клиентов есть бейдж «Разовый», серверный фильтр типа и действие «Сделать постоянным» в действиях строки и карточке.

Перед запуском обновлённого приложения на сервере выполнить `npx prisma migrate deploy`: миграция `20261020120000_client_type`. Локальный Prisma Client сгенерирован через `npx prisma generate`. Миграция добавляет enum и два поля, без удаления или преобразования финансовых записей.

Проверки: `backend/test/quick-clients.test.cjs` проверяет настоящий Nest HTTP-конвейер с mock Prisma, валидацию, минимального гостя, постоянного клиента, фильтры и конвертацию; браузерные mock-сценарии находятся в `frontend/e2e/dashboard.spec.ts` и `frontend/e2e/cash-desk.spec.ts`. Браузерные сценарии не заменяют применение миграции и smoke-проверку с PostgreSQL на сервере.
