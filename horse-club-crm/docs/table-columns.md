# Настройки колонок списков CRM

`frontend/src/hooks/useTableColumns.ts` принимает определения колонок и `storageKey`. У каждой колонки нужен стабильный `key`; основные поля имеют `fixed: 'left'`, действия — `fixed: 'right'`. Настройки фиксированных полей недоступны. `defaultVisible: false` либо `defaultHiddenColumns` в `ConfigurableTable` задают второстепенные поля.

В localStorage хранится массив `{ key, visible }` в выбранном порядке. Парсер игнорирует неизвестные/повторные ключи и некорректные значения, добавляет новые поля с дефолтами, восстанавливается после повреждения JSON. Запрещённые через `hidden` или отсутствующие по RBAC колонки не возвращаются из хранилища. При недоступном storage настройки действуют в памяти; панель показывает предупреждение.

Общие владельцы: `TableColumnSettings` — видимость, кнопки выше/ниже, сброс; `ConfigurableTable` — компактность и Tooltip полного текста; `ResponsiveTable` — карточки на телефоне. Клиенты сохраняют прежний формат и ключ через адаптер `useClientColumns`, используя общий парсер, хук предпочтений и панель. Серверная сортировка, фильтры, пагинация, формы и права остаются прежними.

Расчёт зарплаты, ведомости и ставки персонала используют отдельные ключи `horse_crm_staff_payroll_columns_v1`, `horse_crm_staff_statements_columns_v1`, `horse_crm_staff_rates_columns_v1`. Календарная сетка смен сохраняется.

Дефолтные наборы помещаются на 1366–1440px; дополнительные колонки могут включить локальную горизонтальную прокрутку таблицы. Страница не расширяется. Ширины заданы для ноутбука; действия переносятся внутри ячейки. Фото и кличка лошади объединены. Числа/суммы выровнены справа, статусы и роли — по центру, текст — слева. Tooltip доступен мышью и с клавиатуры.

Проверки: unit-тесты парсера и защиты fixed/RBAC; Playwright `table-columns.spec.ts` проверяет девять списков на 1366/1440px, перезагрузку, независимость ключей, порядок, сброс, Tooltip, Escape, мобильные карточки, READ_ONLY и отказ storage. Миграция Prisma не требуется.

## Результаты проверки — 2026-11-05

- `npm run typecheck`, `npm run lint`, `npm run build`, `npm test` выполнены в обоих проектах. Использован `npm.cmd`, поскольку PowerShell блокирует `npm.ps1`.
- Frontend: 18 файлов, 158 unit-тестов прошли. Backend: 641 тест прошёл, 20 PostgreSQL-проверок пропущены без тестовой базы; линтер сообщил три существующих предупреждения, ошибок нет.
- Playwright mock: `table-columns.spec.ts clients-memberships.spec.ts entity-edit.spec.ts staff-lifecycle.spec.ts staff-payroll-lock.spec.ts` — 77 сценариев прошли. Включены проверки 320/390px, 1366/1440px, прав, CRUD и восстановления после ошибок.
- Для кнопки подтверждения отмены оплаты ведомости добавлен стабильный `aria-label`: уходящий индикатор загрузки Ant Design больше не меняет её доступное имя при повторе после ошибки.
- Дополнительный `audit_project.py --mode strict` сообщил 207 замечаний в существующем коде проекта; в новых общих компонентах замечаний нет. JSON сохранён локально в `docs/table-columns-premium-audit.json` (игнорируется Git). Общий проектный аудит не считается пройденным.
