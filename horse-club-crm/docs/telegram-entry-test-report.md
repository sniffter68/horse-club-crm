# Вход в Telegram Mini App — 23.11.2026

Кнопки персонала в меню бота (`/start`, `/help`, текстовые сообщения) открывают `/tma/trainer`. Клиентские кнопки и общая кнопка меню бота открывают `/tma`; персонал автоматически переходит оттуда в `/tma/trainer` с сохранением query и hash Telegram. При ошибке перехода после определения роли доступна ссылка «Открыть кабинет персонала».

ADMIN и STAFF без карточки тренера проходят `bootstrap` и `authenticate`. ADMIN получает FULL, STAFF — разрешённый уровень расписания своей роли. Ограничения HIDDEN, отключённого доступа и обязательной активной карточки для TRAINER сохранены.

Проверки выполнены через `npm.cmd` (PowerShell блокирует `npm.ps1`):

- Backend: typecheck, lint, build; тесты — 895 прошли, 26 пропущены, ошибок нет. Линтер сообщает три существующих предупреждения в dashboard, vet-records и audit-http.
- Frontend: typecheck, lint, build; 196 тестов прошли.
- TMA: typecheck, lint, build, unit test; 27 браузерных тестов прошли, включая переходы ADMIN/TRAINER/STAFF и клиентские сценарии.
- Размер TMA: 154 960 байт JS + CSS при лимите менее 155 000 байт. Повторяющиеся обработчики вынесены в общие функции; лимит сохранён.

Схема базы данных не менялась. Миграция Prisma не требуется.
