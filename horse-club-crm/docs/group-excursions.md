# Групповые мероприятия и экскурсии

Услуга с `isPerPerson=true` или названием «Экскурсия» тарифицируется за человека. В занятии сохраняются `participantsCount` (1–100) и `pricePerPerson` — снимок ставки каталога либо явно указанная ставка. `cost` по умолчанию равен произведению; явная стоимость имеет приоритет, включая ноль.

Группа оформляется одной записью клиента-организатора. Гостей не требуется заводить отдельными клиентами. Лошадь хранится в существующем nullable `Booking.horseId`; дополнительная связь в `Lesson` не вводится. Лошадь необязательна, сотрудник обязателен. При выбранной локации проверяется вместимость по числу гостей. Групповые экскурсии не объединяются автоматически с другими занятиями и оплачиваются без личного абонемента организатора.

Предоплата и доплата используют существующие Serializable-транзакции занятия, платежи и аудит кассы. В бронировании организатора начисляется вся стоимость группы. Например: 25 × 500 ₽ = 12 500 ₽, предоплата 3 000 ₽, доплата 9 500 ₽. При ручной скидке в карточке отдельно показаны расчет по ставке и итоговая стоимость.

Расписание и быстрая шторка используют общие `LessonPriceFields`; выбор услуги сбрасывает число гостей, ставку и предоплату. Изменение числа гостей пересчитывает стоимость, после чего ее можно корректировать вручную. Создание/перенос в расписании использует общую боковую шторку `EntryOverlay`.

## Развертывание

Применить миграцию `20261020120000_group_excursions` на сервере через `npx prisma migrate deploy` до запуска нового backend. Локально Prisma Client сгенерирован. Миграция не меняет существующие суммы; старые занятия получают число участников 1 и пустую ставку.

## Проверки

Результат локального прогона 20.10.2026: backend — 437 passed / 17 skipped / 0 failed; frontend — 134 passed; Playwright оплаты — 5 passed (после перехода на шторку), повтор экскурсионных сценариев — 2 passed. - Backend: `npm test`, `npm run typecheck`, `npm run build`; тесты групп и оплаты находятся в `backend/test/lesson-payments.test.cjs`.
- Frontend: `npm run typecheck`, `npm run lint`, `npm test`, `npm run build`.
- Playwright: `npx playwright test --project=mock e2e/lesson-payments.spec.ts`, экскурсии на 20 гостей при ширине 1440/390 px, предоплата в кассе и финальная доплата. HTTP API в этих браузерных тестах подменяется; транзакции отдельно проверяются backend mock-тестами.
- В backend нет npm-скрипта `lint`; исходники проверяются установленным Oxlint из frontend.
- Общий strict UI-аудит: `docs/group-excursions-ui-check.json`. Аудит сообщает о существующих замечаниях по проекту и не заменяет браузерные проверки. PostgreSQL-интеграция в локальном прогоне пропускается без настроенной тестовой БД.
