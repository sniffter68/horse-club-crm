# Публичный каталог лендинга

Загрузка фото с компьютера, постоянный Docker volume и инструкция обновления: [image-uploads.md](image-uploads.md).

1. **База и API.** Из каталога `backend` выполнить `npx prisma migrate deploy`, затем `npx prisma generate` и пересобрать backend. Миграция добавляет `isPublic` (по умолчанию `true`, в том числе для существующих записей), `imageUrl`, `description`, `role`, `order` в Horse, Trainer, Service. `GET /api/public/content` доступен без JWT. Возвращает `{ horses, trainers, services }` с разрешёнными полями карточек и ценами услуг, без внутренних данных. Лошади должны быть публичными, иметь `status=active`, `isUnavailable=false`; тренеры — публичными и активными; услуги — публичными. Порядок: `order ASC`, затем `id ASC`.

2. **CRM.** В формах создания и редактирования всех трёх каталогов доступны «Отображать на сайте», ссылка HTTP(S) на фото, описание, роль/направление и порядок. Пустая ссылка очищает фото. Сохранение и права доступа используют существующий CRUD: администратор и менеджер могут редактировать.

3. **Лендинг.** Один запрос при открытии страницы через `usePublicContent`; адрес берётся из `VITE_API_URL` (по умолчанию `/api`). Рекомендуемая production-настройка — `VITE_API_URL=/api`: Caddy уже проксирует API на домене лендинга, дополнительных CORS-настроек не требуется. Внешний API на другом домене потребует отдельной настройки CORS и `connect-src`. В Caddy для лендинга разрешены HTTP(S)-фотографии; на HTTPS-сайте используйте HTTPS-ссылки на изображения.

4. **Fallback.** Пока запрос выполняется, при ошибке/таймауте (8 секунд), некорректном ответе или пустом разделе используются соответствующие массивы из `landing/src/data/landingContent.ts`. Следовательно, отключение всех записей раздела показывает его статичный fallback, как предусмотрено заданием. Данные реальных карточек не дополняются вымышленными биографиями или характеристиками. При отсутствии фотографии используется локальное изображение.

5. **Публикация.** Применить миграцию до запуска новой версии backend, пересобрать CRM и лендинг, загрузить сборки и обновить конфигурацию Caddy. Проверить анонимный `GET /api/public/content`, сохранить запись в CRM, обновить лендинг, затем выключить публикацию и проверить отсутствие записи в ответе API.
