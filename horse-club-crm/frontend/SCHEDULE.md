# Расписание

Маршрут `/schedule` загружает FullCalendar отдельным модулем. Неделя и день показывают часы работы из `/settings/club-schedule`; выходной скрыт (0 — воскресенье). Диапазон запросов `/lessons` и время создания передаются как UTC ISO. Фильтры `trainerId` и `horseId` применяет сервер.

`VITE_CLUB_TIME_ZONE` по умолчанию `Europe/Moscow` и должен совпадать с `CLUB_TIME_ZONE` бэкенда. Для FullCalendar 6 подключён Luxon-плагин: отображение и ввод не зависят от часового пояса компьютера. Неоднозначный или несуществующий локальный момент не отправляется.

ADMIN/MANAGER создают занятие кнопкой или выбором слота/интервала. Выбор услуги задаёт длительность, которую можно изменить. Нагрузка запрашивается для выбранных лошади и клубной даты. Сервер окончательно проверяет пересечения, рабочее время и нагрузку; сообщение HTTP 409 показывается в модалке, заполненные поля сохраняются. Запросы чтения отменяются при смене параметров и уходе со страницы.

Карточка содержит участников, тренера, лошадь, услугу и время. Статусы меняются через PATCH; отмена требует подтверждения, отменённое занятие нельзя перевести в другой статус. TRAINER может менять статусы, но не создавать занятия, согласно правам API. Финансовые и медицинские поля в расписании не выводятся.

Каталоги для выбора загружаются страницами по 100 записей до `x-total-count`; при ошибке загрузки создание блокируется, доступна кнопка «Обновить». Ошибка 401 передаётся обработчику Refine и сбрасывает сессию.

## Проверка

- `npm run build`, `npm run lint`, `npm test`.
- `npm run test:e2e` — реальный API на 3000 и Vite на 5173, пользователь `admin@test.ru` из dev-сида. Сценарий расписания создаёт собственные каталоги, бронирование, проверяет время UTC, нагрузку, три смены статуса, фильтр и вид дня; контролирует `pageerror`/`console.error`. Удаляет только собственные записи через Prisma, поскольку DELETE занятия в API отсутствует.
- `npm run test:e2e:mock` — дополнительно проверяет выбор слота, сохранение формы после 409 и выход при 401 запроса расписания.

Скриншот реального сценария: `e2e-schedule.png`. Тесты времени: `src/pages/schedule/time.test.ts`.
