# Лендинг СЛКС Тамбов

Лендинг сохраняет клубную палитру и типографику из `src/style.css` и существующих компонентов: тёмный шоколад `#241E1C`, седельный акцент `#614535`, бежевый `#E4DAD0`, белая поверхность формы. Основной сценарий — заявка новичка на первое занятие; сведения о клубе и спортивный каталог остаются доступны отдельно.

Этап 1 по `docs/reports/landing-hallmark-audit.md`: equestrian classic / warm minimal. Канонические цвета находятся в `src/style.css` → `@theme`: `club-paper` #FAF7F2, `club-sand` #E4DAD0, `club-ink` #3A2F2B, `club-deep` #241E1C, `club-action` #614535, `club-secondary` #5A483E. Tailwind генерирует из них `text-club-*`/`bg-club-*`; прежние роли `luxury.*` в `tailwind.config.js` ссылаются на эти же переменные. Белый оставлен для формы и текста основного CTA. Эти токены принадлежат только сборке `landing`, тема Ant Design не меняется.

Заголовки используют Georgia первым в serif-стеке, текст — системный sans без загрузки нового шрифта. H1: 40/44px до 1024px, затем clamp(48px, 5vw, 76px)/1.05; единое прямое начертание. H2: 32/36px и 48/54px, основной текст 16px с межстрочным 1.625, подписи минимум 14px, кнопки 15/20px. Caps и разрядка мелких подписей убраны. Hero до 1024px идёт в потоке «текст → всадник», затем — две независимые колонки одного контейнера; изображение не вылетает за свою колонку. Существующий rider сохранён без заявления о происхождении фотографии. Фокус — контур 2px с отступом 3px и светлой подложкой для тёмных секций; reduced motion отключает CSS-анимации и задержанные fade-reveal, JS-трансформации контролирует общий MotionConfig.

`src/booking.ts` владеет названиями услуг и переходом к форме. Hero, навигация и блок первого занятия явно выбирают «Первое занятие по верховой езде». `ContactsSection` показывает выбранную услугу и нативное раскрытие дополнительных вариантов; имя и телефон обязательны, пожелания необязательны. Обязательное согласие сохраняется, политика открывается в нативном модальном dialog с Escape и возвратом фокуса.

Переход фокусирует заголовок формы, контейнер имеет scroll-margin-top 5rem. Ошибки сохраняют данные, успешный ответ API объясняет звонок администратора для согласования времени. Защита от повторной отправки и проверка UUID перед передачей serviceId принадлежат форме; HTTP-контракт остаётся в `src/lead.ts`.

Проверки: `npm run typecheck`, `npm run lint`, `npm run build`, `npm test`. `tests/booking-cro.spec.ts` проверяет путь на 375px, обычную и уменьшенную анимацию, уникальные варианты, отсутствие ID дисциплины в заявке первого занятия, политику и подтверждение API. Остальные сценарии проверяют ошибки, повтор и сохранение контекста CRM.
