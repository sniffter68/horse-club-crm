# Публичный сайт клуба

Лёгкий Vite + TypeScript + Tailwind CSS 4, без React и UI-библиотек. `npm install`, `npm run dev` — http://127.0.0.1:5174. Проверки: `npm run build`, `npm run test:e2e` (Playwright, установленный Microsoft Edge).

## Контент

Все публичные сведения редактируются в `src/content.ts`. Укажите настоящее название, адрес, VK-ссылку (`https://vk.me/…`), ссылку на точку в картах, телефон, цены и длительность услуг. Массивы `trainers`/`horses` принимают `name`, `specialty`, `description`, необязательное `image` (HTTPS URL). После заполнения появятся карточки команды и лошадей. Не публикуются вымышленные имена, цены или адреса. Пока данных нет, сайт предлагает уточнить их в заявке. График 09:00–19:00, понедельник выходной взят из dev-базы 08.09.2026; при изменениях обновляйте публичный контент.

Направления не требуют доступа к закрытому CRM API. При наличии реального UUID услуги заполните `serviceId` соответствующего направления. Иначе выбранное направление передаётся в `preferences`; фиктивные UUID не отправляются.

## API и размещение

`.env`: `VITE_API_URL=/api`. Во время разработки Vite проксирует `/api` на `http://localhost:3000`. В production разместите `dist` и проксируйте `/api` на NestJS на том же домене. Прямой URL API на другом origin потребует отдельно настроенного CORS на backend.

Форма передаёт только поля DTO. Российский телефон маскируется и преобразуется в `+7XXXXXXXXXX`; имя и email проверяются, серверные 400 показываются пользователю. Нет повторной отправки во время запроса, тайм-аут 15 секунд; после ошибки данные остаются в форме. Данные не сохраняются в localStorage. Honeypot отсеивает простых браузерных ботов, но не защищает API от прямых запросов.

Для реальной проверки формы используйте `npm run test:e2e -- tests/live.spec.ts` при работающем NestJS и PostgreSQL. Тест создаёт и удаляет только собственную запись клиента. Все прочие тесты подменяют API и проверяют форму, отсутствие ошибок консоли и горизонтального переполнения на 390/768/1440 px. Скриншоты — `artifacts/`.
