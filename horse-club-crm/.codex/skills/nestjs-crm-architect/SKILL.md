# Стандарты Backend (NestJS)
- Строгий TypeScript: запрещено использование ny, @ts-ignore и нетипизированных объектов.
- Вся входящая нагрузка валидируется через DTO с декораторами class-validator и class-transformer.
- Жёсткая изоляция прав по ролям: роль TRAINER не получает доступ к балансам касс, долгам клиентов и изменению чужих занятий (403 Forbidden).
- Все значимые действия смены (создание/перенос/отмена занятия, отметка проведения, приём платежа) фиксируются в AuditLog.
- Каждый новый сервис и сценарий прав доступа покрывается unit/integration тестами (Jest).
