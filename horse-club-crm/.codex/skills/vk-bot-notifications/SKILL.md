# Правила работы с VK-ботом
- Обработка входящих событий VK Callback API обязана быть идемпотентной (игнорировать дубли по event_id и отвечать ok).
- Привязка клиента или тренера к VK выполняется по внутреннему ID карточки с проверкой корректности peer_id.
- Системные уведомления о новых заявках с лендинга и изменениях расписания отправляются в настроенный peer_id администратора (VK_ADMIN_PEER_ID=2000000001) и ответственного тренера.
- Ошибки доставки VK API логируются без падения основного HTTP-запроса или транзакции создания записи.
